Local Wi-Fi Control

Join the same Wi-Fi network as the ESP32, enter its local address, and connect. A successful connection unlocks the Auto and Manual controls. In Manual mode, use the speed slider or turn the fan fully off.

ESP32 firmware connection requirements

This page expects the ESP32 to serve the following endpoints. Keep this page and the API on the same origin for the simplest setup.

  • GET /api/status returns JSON such as {"temperature":28.6,"fanSpeed":62,"mode":"auto","fanOff":false}.
  • GET /api/control?mode=auto or ?mode=manual changes the mode.
  • GET /api/control?speed=65 sets manual speed from 0 to 100.
  • GET /api/control?off=1 turns the fan off in Manual mode.
  • Each control endpoint returns a JSON acknowledgement such as {"ok":true}.

To operate this control panel reliably, host the page on the ESP32 or on the same local origin. A GitHub Pages HTTPS page may be blocked by the browser when it tries to call an ESP32 HTTP address.
